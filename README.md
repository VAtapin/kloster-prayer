# Православные молитвенные записки и пожертвования

WordPress-плагин для приходов, храмов, соборов и монастырей: молитвенные записки, требы, пожертвования, платежи Stripe и PayPal, PDF-бланки и отчёты.

## Установка

Скачайте [последнюю версию плагина](https://github.com/VAtapin/kloster-prayer/releases/latest/download/kloster-prayer.zip), затем в WordPress откройте **Плагины → Добавить новый → Загрузить плагин** и загрузите ZIP.

После активации откройте **Kloster – Записки → Настройки** и внесите данные Stripe и/или PayPal. Создайте webhook-адреса, показанные на этой странице настроек. Плагин не содержит и не публикует платёжные ключи.

Требования: WordPress 7.1+, PHP 8.4+, HTTPS для Stripe и PayPal.

## Возможности

- формы треб и пожертвований, включая совместимые шорткоды;
- русский, немецкий, украинский и польский переводы;
- Stripe Checkout и PayPal Checkout с проверкой webhook-подписей;
- PDF-бланки здравия и упокоения, CSV-экспорт, печать и отчёты;
- архивирование вместо удаления, журнал событий и повторная отправка подтверждений.

Полная документация по шорткодам, установке и изменениям версий содержится в [readme.txt](kloster-prayer/readme.txt).

## Выпуск

Номер версии должен совпадать в `kloster-prayer/kloster-prayer.php`, `kloster-prayer/readme.txt` и Git-теге. Тег запускает GitHub Actions: проверяются версия и синтаксис PHP, затем создаётся GitHub Release с двумя архивами:

- `kloster-prayer-<версия>.zip` — архив конкретного выпуска;
- `kloster-prayer.zip` — постоянное имя для скачивания последней версии.
