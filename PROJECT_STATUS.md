## Реализовано и принятые решения
- Stripe/PayPal, формы, отчёты, PDF на оригинальных бланках, архив и история записок.
- Печать отмечается автоматически после формирования PDF; дата заказа выводится только на сорокоусте.
- Раздел поминовения и редактор сроков убраны из интерфейса; старые данные не удаляются.
- В настройках оплаты добавлен необязательный HTTPS-домен API. Пустое значение следует за WordPress; переопределение сохраняет путь установки и REST-маршрутизацию.
- Настройка применяется к отображаемым webhook URL и возврату PayPal, не к API-серверам платёжных систем.

## Ограничения и следующие шаги
- Настройка не создаёт DNS, HTTPS-сертификат или алиас в Plesk: домен должен обслуживать тот же WordPress.
- После переезда обновить WordPress URL и адреса webhook в кабинетах Stripe/PayPal; старый домен сохранить для начатых платежей. Старые return_url и платёжные сессии не переписываются.
- Проверить 1.2.4 на PHP 8.4 после восстановления CLI и на тестовом WordPress перед рабочим обновлением.
- Публикация ZIP: проект Kalendar, main → origin/main; production /var/www/vhosts/georg-kloster.ru/kalender.georg-kloster.ru, git pull --ff-only origin main, nodenv local 22, npm ci --include=dev, npm run build. Сам WordPress обновляется отдельно. SSH-подключение не настроено в этой сессии.
