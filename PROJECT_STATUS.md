# Состояние проекта

## Текущее состояние
- Плагин `georg-kloster-orthodox-donations`, версия и Stable tag остаются `1.0.6`; новый tag и публикация не выполнялись.
- Stripe синхронизирует только отмеченные требы из меню действий. Повторная синхронизация обновляет выбранные товары; пустое описание пропускается; цена и рассчитанное количество передаются отдельно.
- Платёжные формы сохраняют фон темы и имеют тонкую серую рамку. Акцент кнопок и выбранных параметров задаётся в редакторе конкретной молитвенной формы или целевого сбора; для отдельного пожертвования/поддержки доступен атрибут `accent_color` шорткода. Акцент применяется ко всем состояниям форм, карточкам сборов и их индикаторам. CSS/JS версии формируются по содержимому файлов для обновления браузерного кэша без повышения версии плагина.
- Гостевой кабинет доступен по многоразовой ссылке из письма. Он показывает пожертвования по указанному email, позволяет пожертвовать снова и отменить регулярную поддержку. Регистрация аккаунта необязательна; привязка к тому же email отключает персональную ссылку.
- В админке есть список жертвователей и карточка с платежной историей и данными плательщика из заказа. Сотрудник может вручную отправить PDF-благодарность по оплаченному заказу; автоматической отправки нет. Для персонализированного письма ожидается PDF-дизайн владельца.
- Новые строки интерфейса включены в POT и RU/DE/UK/PL PO/MO; по 447 сообщений на локаль.
- Ручной ZIP для тестовой установки собран: `output/georg-kloster-orthodox-donations-1.0.6.zip`, 378 файлов, SHA256 `8ff15f33421f40748cca3c2e637ab06ecbf72e9e42a877a2f8fb236fb06a1679`. Production не обновлялся.
