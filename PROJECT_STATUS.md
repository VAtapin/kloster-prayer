# Состояние проекта

## Текущее состояние
- Версия плагина и Stable tag остаются `1.0.6`; Git tag и публикация в WordPress.org не выполнялись. Внутренняя версия схемы БД — `1.0.7` для добавления двух цветовых настроек молитвенной формы.
- Stripe синхронизирует только отмеченные требы из меню действий. Повторная синхронизация обновляет выбранные товары; пустое описание пропускается; цена и рассчитанное количество передаются отдельно.
- Фоны платёжных форм прозрачны, видна тема сайта; вокруг формы остаётся тонкая серая рамка. Цвет переключателя «О здравии» и цвет переключателя «Об упокоении» задаются отдельно в редакторе каждой формы. Кнопки отправки используют оформление темы WordPress. Акцент сбора управляет его индикатором и ссылками.
- Гостевой кабинет доступен по многоразовой ссылке из письма. Он показывает пожертвования по указанному email, позволяет пожертвовать снова и отменить регулярную поддержку. Регистрация аккаунта необязательна; привязка к тому же email отключает персональную ссылку.
- В админке есть список жертвователей и карточка с платежной историей и данными плательщика из заказа. Сотрудник может вручную отправить PDF-благодарность по оплаченному заказу; автоматической отправки нет. Для персонализированного письма ожидается PDF-дизайн владельца.
- Строки интерфейса включены в POT и RU/DE/UK/PL PO/MO; по 451 сообщению на локаль.
- Ручной ZIP для тестовой установки: `output/georg-kloster-orthodox-donations-1.0.6.zip`, 378 файлов, SHA256 `25190a2e9fafc9537c7b6e6480231716a7cbcfb8a7f4fe3863a6677a0e754ad0`. Production не обновлялся.
