# Состояние проекта

## Текущее состояние
- Версия плагина и Stable tag — `1.0.6`; версия схемы БД — `1.0.7`. Тег, публикация и production deployment не выполнялись.
- Полный аудит исходников и доступных без WordPress проверок завершён. Исправлены ошибки обработки сбоев БД в финансовых сводках, таблицах и личной истории; ошибки проверки PayPal webhook теперь отделены от неверной подписи и получают повторную доставку.
- Формы используют уникальный корневой класс, не конфликтуют с CSS темы, не задают фон корню и оставляют кнопки оформления темы WordPress. Цвета переключателей задаются у каждой молитвенной формы; стили таблиц админки остаются WordPress-ными.
- Обновлены Stripe-инструкции и скомпилированы четыре MO-каталога (DE/PL/RU/UK). README приведён к текущей версии без устаревших номеров релиза.
- Ручной установочный пакет `output/georg-kloster-orthodox-donations-1.0.6.zip`: 377 файлов, SHA256 `07296e39422a1d92a679651484e0604b4c521853e1cdd1d4bbda989961c9d790`.
- Механизм ручной отправки персонализированного PDF-благодарственного письма ожидает предоставленный владельцем дизайн PDF.

## Проверки
- PHP syntax: все 287 PHP-файлов плагина, тестов и инструментов прошли `php -l`.
- Без WordPress прошли изолированные тесты API-домена, привязки платежей, PayPal webhook, публичных форм, уведомлений, синхронизации Stripe и ошибок сумм сбора.
- JavaScript syntax: 3 исходных файла прошли `node --check`.
- CSS проверен на баланс блоков, дубли правил в одном контексте, `!important`, фон корня формы, конфликт `.gkod-form`, оформление кнопки и переопределение ширины WP-таблиц.
- PO → MO сборка: по 452 записи в каждом каталоге; новые события Stripe присутствуют во всех четырёх MO.
- Сборщик проверил целостность обоих локальных ZIP и побайтовое соответствие исходникам. Пакет WordPress.org остаётся локальным файлом, не опубликован.
- PDF-тест не запущен до сценария: в доступном PHP 8.4 отсутствует `mbstring`. WordPress не устанавливался и не запускался по инструкции владельца.

## Следующий шаг
