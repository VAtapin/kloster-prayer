## Реализовано
- Целевые сборы: пятиъязычные названия/описания, цель, срок, draft/open/closed; сервер запрещает новые оплаты закрытых и просроченных сборов. Суммы поступлений включают только paid; расходы сотрудник вводит отдельно, публично показываются только агрегаты. Новые шорткоды campaigns/campaign_report; настройки в Campaigns.
- Личная история `[kloster_donation_history]`: только текущий WordPress user_id, без переноса гостевых платежей по email. Сотрудники с manage_options сохраняют административный доступ. Схема 1.2.14 добавляет nullable campaign_id и donor_user_id=0 для старых платежей без удаления данных.
- Все 292 gettext-строки исходного интерфейса на английском. Полные PO/MO переводы ru_RU, de_DE, uk и pl_PL сохранены; прежние переводы публичной формы и пожертвований проверены на точное совпадение. POT обновлён.
- Интерфейс, админка, помощь, письма и подписи PDF используют WordPress gettext. Английский — fallback; язык сохранённого заказа применяется к письмам без изменения языка админки. Пользовательские названия треб, формы и комментарии не переписываются; для английского интерфейса существующие названия форм без английского поля используют немецкие данные.
- Самостоятельное разовое пожертвование: `[kloster_donation lang="ru"]`, произвольная сумма EUR 0,50–999 999,99 без имён и выбора требы. Десятичная сумма проверяется в браузере и на сервере без float-округления.
- Используются существующие Stripe/PayPal checkout, проверка webhook, уведомления и ограничения доступа. Тип `none` уже поддерживается схемой; новые таблицы/migrations не нужны. Пожертвования не создают позиции треб или PDF-бланки; доступны в админке через фильтр типа, архиве и общих/донорских отчётах.
- Stripe/PayPal, формы, отчёты, оригинальные PDF-бланки, архив и история. Комментарии под именами в PDF, списке и карточке. Архивные записки печатаются без восстановления; формирование PDF отмечает печать автоматически. Дата заказа — только на сорокоусте.
- Нормализация имён через запятую; настраиваемый HTTPS-домен API; помощь PayPal с официальными ссылками и правилами Live/Sandbox.
- Уведомления на адрес из настроек: opt-out, очередь, повторы, защита от дублей, отсутствие исторической рассылки. admin_email не используется.
- 1.2.11: стандартный английский readme с раскрытием внешних сервисов/данных, лицензий и сохранения данных после удаления; POT/PO/MO; письма используют логотип/имя текущего сайта.
- Владелец подтвердил 11.10.2026 права на оригинальные ZDRAVIE/UPOKOI и разрешил GPLv2-or-later. Лицензии библиотек, шрифтов и иллюстраций включены в пакет.
- Нормализация входных значений, экранирование вывода, prepared identifiers %i; завершённые платежи проверяются по сумме, валюте и идентификаторам заказа. PayPal return проверяет сохранённый token перед capture.
- Исправлен формат dbDelta; схема 1.2.11 выполняет совместимую проверку без удаления данных.
