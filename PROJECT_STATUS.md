## Ограничения и следующие шаги
- Установить ZIP 1.2.10 через WordPress. Изменение не требует новой миграции БД; перед обновлением рекомендуется обычная резервная копия сайта. Email уведомлений сохраняется.
- Интеграционная проверка dbDelta на настоящей WordPress/MySQL и реальная SMTP-доставка не выполнялись.
- Успех wp_mail означает передачу почтовой системе, не доставку в Inbox. При аварии между отправкой и сохранением результата возможен повтор письма.
- Требования WordPress.org по внешним сервисам и полный аудит готовности к каталогу остаются отдельной незавершённой задачей.
- Страница скачивания Kalendar подготовлена для 1.2.9; установка текущего ZIP выполняется отдельно. Git push не означает обновление рабочего сайта.
